# Чек-лист: постоянное меню + генерация фото (проверка вживую)

Код уже задеплоен на сервер (коммит `1f33c4d`), сервис `content-bot` перезапущен
и работает. Ниже — 10 шагов ручной проверки в реальном Telegram-аккаунте.
Автотестами это не проверяется (нужен настоящий бот и настоящий чат).

## Шаги проверки

1. **Деплой.** Уже выполнен — `sudo systemctl status content-bot` на сервере
   показывает `active (running)`, запущен без ошибок.

2. **Старый чат без кнопки СТАРТ.** Открой чат с ботом, где уже есть история
   сообщений (не новый чат) — убедись, что стандартной синей кнопки
   "START" от Telegram больше НЕТ. Это как раз та проблема, которую чинили.

3. **Первый `/start`.** Отправь `/start` один раз — должно появиться:
   - приветствие, а под ним внизу экрана — постоянная кнопка **«Старт»**;
   - следующим сообщением — **«Что делаем дальше?»** с двумя кнопками:
     **«Я умею»** и **«Создать пост сейчас»**.

4. **Кнопка «Старт» работает как /start.** Закрой чат, открой заново, нажми
   кнопку **«Старт»** внизу экрана (не набирай `/start` руками) — должно
   появиться то же самое приветствие + меню.

5. **«Я умею».** Нажми — должен появиться текст с описанием возможностей:
   сайт, генерация фото, авторский стиль, 4 языка.

6. **«Создать пост сейчас».** Нажми — должны появиться три кнопки:
   **«МОЙ САЙТ»**, **«Генерация текста»**, **«Генерация фото»**.

7. **«МОЙ САЙТ».** Нажми — сайт должен открыться прямо внутри Telegram
   (как Mini App), а не в отдельном браузере.

8. **«Генерация текста».** Нажми — появится подсказка; затем пришли реальную
   ссылку/голосовое/текст — обычная генерация поста должна работать как раньше.

9. **«Генерация фото».** Нажми, опиши картинку словами — бот должен
   сгенерировать и прислать фото, а затем предложить прислать текст/ссылку/
   голосовое для поста.

10. **Публикация с фото.** После шага 9 пришли текст — бот подготовит варианты
    поста, а кнопка **«Опубликовать в канал»** должна выложить пост **с фото
    из шага 9** прикреплённым.

## Дополнительно: проверка исправленного бага

11. **Кнопка «Старт» — аварийный выход.** Нажми «Генерация фото», но вместо
    описания картинки отправь любую команду (например `/site` или снова
    «Старт»). Ожидается: бот НЕ должен воспринять команду как описание
    картинки и НЕ должен запускать платную генерацию — вместо этого должно
    открыться обычное меню. (Раньше это было багом: бот застревал в режиме
    ожидания описания и любое сообщение — включая команды — трактовал как
    запрос на генерацию.)

## Что делать при расхождении

Если какой-то пункт не совпал — напиши номер шага и что увидела вместо
ожидаемого (текст сообщения, скриншот). VK-автопубликация в этот чек-лист
не входит — это отдельный проект в будущем.

**Чек-лист ручной проверки (выполнить после деплоя, нужен реальный Telegram-аккаунт):**

2. Нажать кнопку — должно открыться редактируемое поле ввода с плейсхолдером «Например: психология».
3. Написать «психология» и отправить — должно прийти подтверждение сохранения темы, затем сам дайджест (новости/статьи/методики — какие направления в этот день дали результат).
4. Нажать «Собрать дайджест свежих новостей» ещё раз — дайджест должен собраться сразу по сохранённой теме «психология», без повторного запроса темы, и показать кнопку «Написать тему».
5. Нажать «Написать тему», ввести другую тему (например, «бухгалтерский учёт») — старая тема должна замениться новой, дайджест — прийти по новой теме.
6. Дождаться 09:00 по МСК (или временно поменять `DIGEST_SEND_HOUR` в `.env` на близкое к текущему времени сервера) — бот должен сам, без каких-либо действий пользователя, прислать дайджест по сохранённой теме.
7. Проверить на аккаунте не из вайтлиста — везде должен быть стандартный отказ «доступ ограничен», ни один из шагов выше не должен сработать.

- Задача от владельца: под дайджестом, ниже уже существующей кнопки «Хотите

  предложение вставить образцы своих постов (не менее 5) → бот считывает
  личный почерк и пишет пост с хэштегами.
- Согласованный сценарий (решения владельца по ходу обсуждения): выбор пункта
  дайджеста — кнопками с номерами, сразу после нажатия авторской кнопки;
  образцы — по одному сообщению со счётчиком «принято N из 5»; если образцы
  уже сохранены — развилка «Писать сразу / Загрузить новые»; площадка
  (Telegram / VK / обе) спрашивается в конце; на выходе 3 варианта с
  хэштегами.
- Фича почти целиком собирается из готового: таблица `style_examples` и
  команда `/settov` уже собирают образцы, `content_generator.build_prompt()`
  уже умеет вклеивать их в промпт, `content._send_variants` уже рассылает
  варианты с кнопками доработки.
- По ходу дизайна нашлась существующая проблема: `bot/handlers/refine.py`
  зовёт `generate_variants()` **без** `style_examples` — то есть кнопка «Ещё
  вариант» уже сегодня отдаёт текст не в авторском стиле, хотя исходные
  варианты были в стиле. Чинится в рамках этой же работы (задача 7 плана).
- Осознанно вне рамок: кнопка не появляется под ежедневным дайджестом от
  планировщика — он шлётся вне диалога, FSM-состояния для него нет.
- Известное ограничение: FSM-хранилище in-memory, при перезапуске бота список
  пунктов дайджеста теряется. Обрабатывается сообщением «дайджест устарел»,
