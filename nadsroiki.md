# MINI_APP_URL — что сделано и что осталось (продолжим позже)

## Что сделано

Файла `.env` в проекте раньше не было (только шаблон `.env.example`, сам `.env` в `.gitignore`).

1. Создан `.env` из шаблона `.env.example`.
2. В `.env` добавлена переменная:
   ```
   MINI_APP_URL=https://olgashomrina.github.io/my-lending-test/
   ```
3. Та же переменная (с описанием, но пустым значением) добавлена в `.env.example` — строки 69-71:
   ```
   # Ссылка на задеплоенный Mini App (веб-страницу), которую бот открывает
   # внутри Telegram.
   MINI_APP_URL=
   ```

## На что обратить внимание при продолжении

1. В новом `.env` остальные переменные (`BOT_TOKEN`, `AI_PROXY_API_KEY`, `OWNER_CHAT_ID`) пустые — их нужно заполнить, иначе бот не запустится.
2. `MINI_APP_URL` пока нигде не используется в коде (проверено через grep) — если планируется открывать эту ссылку как Mini App из бота, нужно будет добавить код, который её читает и передаёт в кнопку/WebApp (например, `InlineKeyboardButton` с `web_app=WebAppInfo(url=...)`).
