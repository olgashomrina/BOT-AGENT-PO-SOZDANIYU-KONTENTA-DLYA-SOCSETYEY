# Ручные шаги для запуска пилота bot↔сайт (после 2026-07-24)

Код пилота (10 задач) уже реализован, проверен (269/269 тестов) и слит
локально в `feature/mvp1-bot` (14 коммитов впереди GitHub). Осталось 4
ручных шага, чтобы пилот заработал вживую.

Реальный IP сервера: `147.45.175.189` → домен для API:
`147-45-175-189.sslip.io` (уже готов, ничего не нужно заменять).

## Шаг 1 — Отправить код на GitHub

Это запустит автодеплой (Фаза 16) — бот на сервере перезапустится с новым
кодом. Безопасно: старый функционал бота не меняется, просто добавляется
внутренний веб-сервер на порт 8080 (пока никому не виден снаружи).

```bash
git push
```

Проверить, что деплой прошёл: подождите 1-2 минуты, затем на сервере
```bash
sudo systemctl status content-bot
```
— должно быть "active (running)", без ошибок в последних строках.

## Шаг 2 — Настроить HTTPS для API (nginx + certbot)

Подключитесь к серверу по SSH и выполните:

```bash
sudo apt install -y nginx certbot python3-certbot-nginx

sudo tee /etc/nginx/sites-available/content-bot-site-api > /dev/null <<'NGINX'
server {
    listen 80;
    server_name 147-45-175-189.sslip.io;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
    }
}
NGINX

sudo ln -s /etc/nginx/sites-available/content-bot-site-api /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx

sudo certbot --nginx -d 147-45-175-189.sslip.io
```

`certbot` спросит email и согласие с условиями — введите свою почту,
согласитесь. Сертификат обновляется автоматически дальше.

**Проверка этого шага:**
```bash
curl https://147-45-175-189.sslip.io/content/services/card_1
```
Ожидаемый ответ (пока ничего не залито через бота):
```json
{"error": "not_found"}
```
Если видите этот ответ без ошибок сертификата — шаг 2 готов.

## Шаг 3 — Один раз подключить скрипт к сайту (в ДРУГОМ репозитории, my-lending-test)

Это НЕ в этом репозитории. Инструкция и сам файл уже готовы здесь:
`bot_site/README.md` и `bot_site/site-content-loader.js`.

Коротко:
1. В репозитории сайта, в `services.html`, у карточки услуги «Принятие тела»
   добавьте `id="pilot-card-text"` на текст описания и `id="pilot-card-photo"`
   на её `<img>`.
2. Скопируйте `site-content-loader.js` в корень репозитория сайта.
3. Перед `</body>` в `services.html` добавьте:
   ```html
   <script src="site-content-loader.js" data-api-base="https://147-45-175-189.sslip.io"></script>
   ```
4. Закоммитьте и запушьте в репозиторий сайта — GitHub Pages пересоберёт
   страницу за 30-60 секунд.

Полная версия инструкции — в `bot_site/README.md`.

## Шаг 4 — Проверка вживую

1. В боте: сгенерируйте любой пост с фото, нажмите «Залить на сайт» —
   должно появиться «Готово! Карточка на сайте обновлена.»
2. Откройте `https://olgashomrina.github.io/my-lending-test/services.html`
   в обычном браузере — карточка «Принятие тела» должна показать новый
   текст/фото.
3. В боте: команда `/site` → «Забрать карточку «Услуги»» — бот должен
   прислать AI-варианты на основе того же текста.
4. В боте: команда `/site` → «МОЙ САЙТ» — должен открыться реальный сайт
   прямо внутри Telegram.

Если что-то не совпало — сначала проверьте консоль браузера (F12 →
Network) на странице сайта: запрос к
`https://147-45-175-189.sslip.io/content/services/card_1` должен быть
`200 OK`, а не ошибка сети/CORS/сертификата.
