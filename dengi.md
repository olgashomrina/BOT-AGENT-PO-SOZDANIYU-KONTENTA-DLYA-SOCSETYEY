# Деньги: себестоимость ИИ-вызовов и защита баланса

Журнал работы по экономике бота — цены, лимиты, учёт расхода.

## 2026-07-30

### Что искали

Владелец сообщила: голосовые сообщения не работают, в параллельной сессии codex
пишет о недостатке денег на vsegpt.ru. Заявлено: «заплатила за безлимитный
тариф, не хватает даже на тест». Цель — безлимитная работа бота при расходе
не больше 200 ₽/мес.

### Что нашли

**1. Локальный `.env` сломан.** В строке 12 `AI_PROXY_API_KEY` содержит токен
Telegram-бота, а не ключ VseGPT (оба начинаются с `8819677652:A…` — копипаста).
Проверено живыми запросами к `api.vsegpt.ru`:

```
GET  /balance                → 403 {"error": {"message": "Incorrect API key.", "code": 403}}
POST /audio/transcriptions   → 403 {"error": {"message": "Incorrect API key.", "code": 403}}
POST /chat/completions       → 403 {"error": {"message": "Incorrect API key.", "code": 403}}
```

Локально не работает ни голос, ни текст, ни картинки — и причина не в деньгах.
Нужен реальный ключ VseGPT (`sk-or-vv-…`) из личного кабинета.

**2. На проде (Timeweb) — действительно баланс.** Проверить напрямую из этой
сессии нельзя (серверный `.env` недоступен), но данные codex совпадают с уже
зафиксированным в `bot/config.py:22-26` наблюдением от 29.07: `img-flux/pro1.1`
незаметно слил баланс.

**3. Тариф VseGPT не оплачивает использование API.** Подписка (199 ₽ Базовый /
399 ₽ Профессиональный за 30 дней) даёт доступ к моделям, снятие лимитов на
частоту запросов и автопополнение. «Неограниченные запросы» в их описании — про
их собственный веб-чат. Каждый вызов API списывается с баланса по факту.
Это корень недоразумения «заплатила за безлимит, а денег нет».

### Цены (живой каталог `api.vsegpt.ru/v1/models`, 30.07.2026)

Тарификация STT: 1 токен = 1 секунда аудио, цена указана за 1000 токенов.

| Операция | Цена каталога | В пересчёте |
|---|---|---|
| `stt-openai/whisper-1` | 20.00 / 1000 с | **1.20 ₽/мин** |
| `stt-openai/gpt-4o-mini-transcribe` | 16.00 / 1000 с | **0.96 ₽/мин** |
| `stt-openai/gpt-4o-transcribe` | 32.00 / 1000 с | 1.92 ₽/мин |
| `stt-deepgram/nova-3` | 20.00 / 1000 с | 1.20 ₽/мин |
| `openai/gpt-4o-mini` | 0.02 / 0.08 за 1000 токенов | ~0.25 ₽ за 2 варианта поста |
| `img-flux/flux-2-klein-4b` | 3.9 | **3.90 ₽/картинка** |
| `img-flux/pro1.1` | 10.0 | **~10–15 ₽/картинка** |

Полный цикл «голосовое 1 мин → 2 поста → 1 картинка»: ~5.4 ₽ с дешёвой
картинкой, ~12–17 ₽ с pro1.1. **Голос — 8–20 % чека, картинки — 70–90 %.**
На 200 ₽: ~160 циклов без картинок, ~37 с klein, ~13 с pro1.1.

### Альтернативы для распознавания речи

| Вариант | ₽/мин | Подвох |
|---|---|---|
| VseGPT `whisper-1` (было) | 1.20 | — |
| VseGPT `gpt-4o-mini-transcribe` | 0.96 | −20 %, одна строка конфига |
| SaluteSpeech (Сбер) | 0 до 100 мин/мес, далее 1.20 | 100 мин на аккаунт, не на юзера |
| Yandex SpeechKit | дороже; точную цену не подтвердили (страница под капчей) | пробный месяц |
| Groq `whisper-large-v3-turbo` | ~0.06 | оплата в USD, доступ с РФ-сервера под вопросом |
| faster-whisper на своём VPS | 0, безлимит | текущий Timeweb 1 vCPU / 1 ГБ слаб, нужен апгрейд до 2 vCPU / 4 ГБ + ffmpeg |

Вывод: «безлимитного Whisper» за 200 ₽/мес не продаёт никто. 200 ₽ — это
бюджет на тесты владельца. Настоящий безлимит на голос даёт только
self-hosted faster-whisper (фиксированная плата за сервер вместо поминутной).

### Решения владельца

- Голос: остаёмся на VseGPT, но переключаем на `gpt-4o-mini-transcribe`
  + лимит длины голосового.
- Ограничители: выбор делегирован ассистенту → берём все четыре (лимит длины
  голосового, дневной лимит картинок на пользователя, предупреждение владельцу
  о низком балансе, учёт расхода в рублях по пользователю).

### Что сделано в коде

1. **Модель распознавания** → `stt-openai/gpt-4o-mini-transcribe` по умолчанию
   (0.96 ₽/мин вместо 1.20 ₽/мин). `bot/config.py`, `.env.example`.
2. **Лимит длины голосового** — `MAX_VOICE_DURATION_SECONDS`, по умолчанию 180 с.
   Проверка в `bot/handlers/content.py::_reject_overlong_voice` стоит до
   скачивания файла, так что отклонённое голосовое не стоит ничего. Новые строки
   `error_voice_too_long` во всех четырёх локалях.
3. **Дневной лимит картинок на пользователя** — `DAILY_IMAGE_LIMIT`, по
   умолчанию 3. Отдельный счётчик в новой таблице `image_usage_log` (картинка
   стоит ~16 постов текста, общая квота её не сдерживает). Правило в одном месте
   — `bot/handlers/image_budget.py::ensure_image_budget`, подключено ко всем трём
   местам генерации: кнопка «Картинка от ИИ», кнопка «Сделать реалистичнее»,
   генерация фото из меню `/start`. В upgrade-пути проверка стоит **до**
   `claim_image_prompt`, чтобы отказ не съедал одноразовый промпт.
4. **Предупреждение о балансе** — `bot/services/balance_watcher.py`, проверка раз
   в час (`BALANCE_CHECK_INTERVAL_SECONDS`), порог 50 ₽
   (`BALANCE_ALERT_THRESHOLD_RUB`). Пишет владельцу один раз на пересечение
   порога, а не каждый час, и снова вооружается, когда баланс поднялся.
   В тексте — на сколько картинок/минут голоса хватит остатка и напоминание,
   что тариф не оплачивает использование API.
   `ai_gateway.get_balance()` разбирает ответ `GET /balance` терпимо: формат
   ответа vsegpt.ru не документирован и живым ключом проверить не удалось
   (единственный доступный ключ отклонён), поэтому парсер ищет число под
   ключом вида `balance`/`credit`/`amount` на любой глубине, а при неудаче
   логирует сырое тело — так реальную форму можно будет уточнить с прода.
5. **Учёт расхода в рублях** — `bot/services/cost_tracker.py` (снимок цен
   каталога), таблица `cost_log`, `bot/storage/costs.py`, команда `/costs`
   (только владельцу, `bot/handlers/costs.py`): итог за месяц, разбивка по
   операциям и по пользователям. Учитываются картинки и расшифровка;
   текст постов (~0.25 ₽ за цикл, <5% расхода) намеренно не детализируется —
   это потребовало бы прокинуть счётчики токенов через каждый вызов шлюза.
   Об этом сказано и в самом отчёте `/costs`.

Тесты: 525 зелёных (было 516 до этой работы).

### Что осталось на стороне владельца (по состоянию на 30.07)

- **Починить локальный `.env`**: подставить настоящий ключ VseGPT
  (`sk-or-vv-…`) в `AI_PROXY_API_KEY` вместо токена бота.
- **Пополнить баланс VseGPT** — 200 ₽ это ~160 циклов без картинок, ~37 с
  дешёвой картинкой, ~13 с pro1.1.
- Проверить на проде, что серверный `.env` содержит правильный ключ, и
  задеплоить эти изменения (миграции не нужны — обе новые таблицы создаются
  через `CREATE TABLE IF NOT EXISTS` в `init_db`).

## 2026-07-31

### Баланс прода измерен напрямую — гипотеза подтверждена

Переезд на Beget отменён (Timeweb оплачен до 14.09.26), вернулись к деньгам.
Запрос выполнен **на самом сервере**, чтобы ключ не покидал его:

```bash
ssh root@147.45.175.189 'set -a; . /opt/content-bot/.env; set +a;
  curl -s -H "Authorization: Bearer $AI_PROXY_API_KEY" https://api.vsegpt.ru/v1/balance'
```

Ответ:

```json
{"status":"ok","data":{"credits":"0.017680","subscription_status":"ok",
 "subscription_end":"2026-08-22 07:34:58","user_status":2,
 "user_status_text":"Less than 10 credits on account. Less than 4.0 credits on account. "}}
```

**Баланс — 0.0177 ₽.** Подписка при этом активна до 22.08.2026 — ровно та
картина, из-за которой возникло недоразумение «заплатила за безлимит, а не
работает»: подписка жива, денег на использование нет.

Ключ на проде правильный (`sk-or-vv-…`, 73 символа) — в отличие от локального
`.env`. Модель распознавания на проде пока `stt-openai/whisper-1`: новый код
ещё не задеплоен.

Проверочный вызов генерации показал точный отказ:

```json
{"error": {"message": "Potentially out of budget: 32->700, expected price 0.05664,
 but you have only 0.017680 on account. Please, add some money to balance
 to proceed: https://vsegpt.ru/User/Money", "code": 400}}
```

Заодно выяснен формат `GET /balance`, который вчера не удалось проверить:
авторизация — заголовком `Authorization: Bearer`, число лежит в
`data.credits` **строкой**. Написанный вчера терпимый парсер эту форму
разбирает верно; теперь она закреплена тестом на реальном ответе.
Другие варианты авторизации (`?api_key=`, `x-api-key`, POST) не работают.

### Что сделано в коде

6. **Отдельная ошибка «кончились деньги»** — `AIGatewayOutOfBudgetError`.
   Раньше отказ по балансу приходил как HTTP 400 и попадал в общий
   `AIGatewayInvalidResponseError`, а пользователь видел «не удалось получить
   корректный ответ от ИИ-модели» — то есть ровно то сообщение, из-за которого
   день ушёл на поиск бага в боте вместо пополнения счёта. Теперь 4xx с
   маркерами (`out of budget`, `add some money`, `insufficient`, …)
   распознаётся отдельно, не ретраится (ответ не изменится, пока нет денег) и
   показывает пользователю честное «сервис временно недоступен, владелец
   уведомлён» — новый ключ `error_out_of_budget` во всех четырёх локалях.
   Подключение к хендлерам — одной строкой в `_AI_ERROR_KEYS`, поэтому
   действует сразу во всех местах генерации.

Тесты: 530 зелёных (было 525).

### Переезд на openrouter.ai

Владелец решила уйти с VseGPT. У неё уже оплачен OpenRouter — проверено
живым запросом с её ключом: `{"data": {"total_credits": 20,
"total_usage": 1.2842976}}`, то есть **$18.72 ≈ 1721 ₽**. Против 0.0177 ₽
на VseGPT, так что переезд заодно чинит и текущий простой.

**Все три эндпоинта совместимы — код запросов менять не пришлось.**
Проверено вживую тем же форматом, что шлёт бот:

| Что | Результат | Цена |
|---|---|---|
| `/chat/completions` | 200 | 13.8 ₽/1M токенов против 20 ₽ |
| `/audio/transcriptions`, `openai/whisper-1` | 200, `{"text":…, "usage":{"seconds":1,"cost":0.0001}}` | 0.55 ₽/мин против 1.20 ₽ |
| `/audio/transcriptions`, `openai/gpt-4o-mini-transcribe` | 200 | ~0.28 ₽/мин против 0.96 ₽ |
| `/images/generations`, `openai/gpt-5-image-mini` | 200, `data[0].b64_json` — ровно то, что бот разбирает | **0.78 ₽/картинка против 3.90 ₽** |

Слаги у OpenRouter без приставки `stt-`. Оплата только в долларах (карты РФ
не работают, официально — USDC с комиссией 5%), поэтому VseGPT остаётся
запасным вариантом: `.env.example` описывает оба блока настроек целиком.

### Что сделано в коде

7. **Проверка баланса под провайдера.** У OpenRouter это `GET /credits`, и
   там ловушка: `total_credits` — это сумма всех пополнений за всё время, а
   остаток равен `total_credits - total_usage`. Вчерашний терпимый парсер
   вернул бы 20 вместо 18.72, и предупреждение о низком балансе не сработало
   бы никогда. Поэтому у OpenRouter явный читатель, а не обход JSON.
8. **Валюта.** `get_balance()` теперь всегда возвращает рубли: OpenRouter
   считает в долларах, а весь бюджет проекта — рублёвый (порог
   предупреждения, `/costs`, оценки «хватит на N картинок»). Пересчёт по
   `USD_RUB_RATE` (по умолчанию 92) — грубая константа для предупреждений,
   по ней ничего не списывается.
9. **402 Payment Required** — распознаётся как «кончились деньги» по одному
   коду, без разбора тела: так OpenRouter сообщает о пустом счёте, тогда как
   VseGPT отдаёт 400 с объяснением в теле.
10. **Формат аудио определяется по байтам** (`_audio_part_metadata`).
    Найдено при сквозной проверке: бот подписывал **любое** аудио как
    `telegram-voice.ogg` / `audio/ogg`. Для голосовых это верно, но
    `handle_voice` принимает и `message.audio` — то есть mp3, m4a, wav,
    которые уезжали с враньём в метаданных. VseGPT это прощал, OpenRouter
    отвечает голым `Provider returned 400`. Теперь контейнер определяется по
    сигнатуре (OggS/RIFF/fLaC/ID3/ftyp/EBML) с откатом на ogg.
11. **Цены OpenRouter** добавлены в `cost_tracker` — замеренные, не из
    документации.

Сквозная проверка через собственный код бота (`load_settings` →
`get_balance` → `generate_text` → `transcribe`): баланс 1721.05 ₽, текст
генерируется, расшифровка доходит до модели. Тесты: 587 зелёных.

### Осталось

- Переключить прод: серверный `.env` (адрес, провайдер, ключ, слаги моделей)
  и деплой накопленных коммитов.
- Отменить автопродление подписки VseGPT (активна до 22.08.2026), иначе
  спишется ещё раз за неиспользуемый сервис.

### Переезд на OpenRouter не состоялся: блокировка по IP сервера

Переключение прода выполнено и **откатано** в тот же час. Причина: с сервера
Timeweb (`147.45.175.189`) openrouter.ai отвечает 403 на всё подряд:

```
GET /api/v1/credits  (с ключом)   -> 403 {"success": false, "error": "Access denied by security policy."}
GET /api/v1/models   (без ключа)  -> 403
GET /                (главная)    -> 403
```

Публичный список моделей и главная страница блокируются так же, как
запрос с ключом, и смена User-Agent не помогает — значит блокировка по IP
российского хостинга, а не по ключу и не по аккаунту. С домашнего
компьютера владельца тот же ключ работает без нареканий: там и баланс
читается, и распознавание, и картинки.

Порядок действий был: бэкап `.env` → переключение на OpenRouter → деплой
кода → обнаружен 403 в логах при первой же проверке баланса → восстановление
`.env` из бэкапа → рестарт. Итог: прод снова на vsegpt.ru, сервис `active`,
`/balance` с сервера отвечает 200. Простой — минуты.

**Код при этом остался задеплоенным и он провайдеро-независимый:** лимиты,
предупреждение о балансе, `/costs`, понятная ошибка при нехватке денег и
определение формата аудио работают одинаково с любым прокси.

Варианты дальше:

1. Пополнить vsegpt.ru — бот работает сегодня, больше ничего не меняется.
2. Перенести сервер за пределы РФ — тогда OpenRouter доступен и расходы
   падают в 2–5 раз. Beget этого бы не решил: он тоже российский.
3. Ходить на OpenRouter через прокси с сервера — лишняя точка отказа.
